# rust-lisp

A simple LISP interpreter, written in Rust, as a learning exercise.

Functionality is currently limited to generating an AST from an input string representing an expression from a subset of LISP.

## Quickstart

Simply edit `main()` and change `input` to your desired LISP expression.

Run via `cargo run` and both the tokenized form and AST expression will be displayed. Or it will panic :)
